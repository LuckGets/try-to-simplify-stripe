# Try-to-Simplify-stripe

Repository นี้เป็น repo เอาไว้เก็บ source code และ`(จะพยายาม)`เป็นแนะนำและเป็นตัวอย่างในการ integrate หนึ่งใน payment gateway ยอดนิยมอย่าง Stripe โดยใช้เทคโนโลยีในการพัฒนาเว็บไซต์แบบ Full-stack ตามนี้

### Front-end

- React

### Back-end

- Node.js

และใน repository นี้จะ integrate ตัวของ [Stripe Element](https://docs.stripe.com/payments/elements) เข้ามาใน Front-end part โดยไม่ได้มีการ redirect ไปที่หน้า website ที่ stripe hosted ไว้ให้ สามารถดูได้เพิ่มเติมใน [checkout-page.md](./checkout-page.md)

ก่อนจะเริ่มเข้าไปดู source code ถ้าให้ดีแนะนำลองอ่าน [Flow ในการชำระเงิน](./FLOW.md) เพื่อทำความเข้าใจก่อนที่จะเข้าไปดู code ตรงๆนะครับ

โดยใน repository นี้ได้แบ่ง branch เป็นขั้นตอนในการเริ่ม integrate ได้ตามขั้นตอนด้านล่าง สามารถกดคลิกเพื่อเข้าไปดูในแต่ละ branch ตามลำดับขั้นได้ครับ
